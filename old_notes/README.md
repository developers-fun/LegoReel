## r6_roblox_style/ (archived 2026-11-20)
The first figure: Roblox-R6-style proportions from community-cross-checked joint values.
- r6.json: part sizes and joints (head 2x1x1 with 1.25 mesh, torso 2x2x1, arms and legs 1x2x1, height 5.125 studs).
- main.json: the placeholder avatar (v2) with variants jacket, plain, host, guest.
- house_v2.json: the house style as it was when this figure was retired.
- last_look.png: the last test frames with this figure.
Why it was retired: the owner wants a toy-brick minifigure look with swappable faces, hair and other parts. The R6 code path (rig "r6") still works if a scene asks for it.
